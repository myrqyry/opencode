# SDK Documentation Site

This directory contains a separate Mintlify site configuration with an SDK navigation tab in `docs.json`; the main OpenCode website and product documentation are maintained in `packages/web`. Several pages here still contain generic Mintlify starter content.

With the Mintlify CLI installed, preview this site by running `mint dev` from `packages/docs`, where `docs.json` is located. Use the URL printed by the CLI for the local preview.

This directory has no package-specific install, build, or deployment scripts. No publishing workflow for this site is defined in this repository, so confirm its ownership and deployment path before treating it as current SDK documentation.
